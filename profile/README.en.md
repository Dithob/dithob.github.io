## What I work on

- **AI Applications**: an agent for paper search, reading, translation, and note-taking (PaperQAAgent); an AI-native app for resumes, JD matching, and learning-roadmap planning (DeepResume); and workflows that distill talks and articles into structured knowledge bases.
- **Agent & Developer Tools**: turning repeated work into installable, verifiable skills and CLIs — image understanding and OCR (Youcansee), subtitle and media distillation (media-content-distiller), note archiving and daily reports — plus a local-first session monitor for AI coding agents (maodingAgent).
- **Engineering Quality**: an API test framework built on Pytest, Requests, OpenAPI, and CI (autotest-framework); Golden Dataset and bad-case feedback loops that validate AI output with keywords, JSON Schema, similarity, and rule assertions.

## My workflow

1. **Verify first**: check claims against public repos, issues, and run logs; label conclusions as verified / inferred / to-confirm — never treat model output as fact, and never describe static checks as live-service success or forks as original work.
2. **Shape the system**: turn repeated workflows into skills, CLIs, and scripts (image reading, subtitle distillation, note archiving, daily reports), keeping reviewable intermediate artifacts. Currently building:
   - PaperQAAgent: page-linked evidence and paper research workflows
   - DeepResume: connecting resumes, JDs, learning plans, and career evidence
   - Installable, verifiable, and boundary-aware agent skills and CLIs
3. **State the boundary**: put quick starts, evidence, and limitations at the project entrance; ship test evidence (pytest suites, Golden Dataset regression) and next steps — and keep credentials out of code, logs, repositories, build artifacts, and public profiles.
