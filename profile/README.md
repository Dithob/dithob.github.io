# 你好，我是 wujue 👋

计算机科学与技术学生，关注 **AI 应用、Agent 工具与测试工程**，聚焦 RAG、OCR 与文档理解方向。

> 构建可运行、可解释、可核验的 AI 工具。

## 我在做什么

- **AI 应用**：专门用于论文检索、阅读、翻译与整理的 Agent（PaperQAAgent）；用于制定简历、JD 匹配与学习路线的 AI Native 应用（DeepResume）；以及把讲座、文章蒸馏成结构化知识库的工作流。
- **Agent & Developer Tools**：把重复流程做成可安装、可验证的 Skill 与 CLI——读图与 OCR（Youcansee）、字幕与媒体蒸馏（media-content-distiller）、笔记归档与日报生成；另做本地优先的 AI 编程 Agent 会话监控器（maodingAgent）。
- **Engineering Quality**：基于 Pytest、Requests、OpenAPI 与 CI 的 API 测试框架（autotest-framework）；构建 Golden Dataset 与 Bad Case 回流闭环，用关键词、JSON Schema、相似度与规则断言批量校验 AI 输出。

## 我的工作流

1. **先确认事实**：对照公开仓库、issue 和运行日志核实信息，结论标成「已验证 / 推断 / 待确认」，不把 AI 输出直接当事实，也不把静态检查写成线上服务成功、把 fork 写成原创。
2. **再组织系统**：把重复流程沉淀成 Skill、CLI 或脚本（读图、字幕蒸馏、笔记归档、日报生成），保留可回看的中间产物。现在主要推进：
   - PaperQAAgent：页面级证据与论文阅读工作流
   - DeepResume：简历、JD、学习计划和职业证据闭环
   - 可安装、可验证、边界清晰的 Agent Skill 与 CLI
3. **最后说明边界**：把快速开始、验证证据和当前限制放在项目入口，交付附上测试证据（pytest 用例、Golden Dataset 回归）与下一步计划；凭据不进入代码、日志、仓库、构建产物或公开主页。
